# Чёрная комната: настройки и тестовые диалоги

ЧК — отдельная `rBlackRoom` между порталом игрового уровня и его статистикой.
Комната редактируется в GameMaker: игрок, портал, невидимый пол, границы и
небольшое препятствие находятся в её слоях. В ЧК нет ягод, ОС, врагов и HUD.
Игрок может двигаться, прыгать, атаковать и бросать меч до разговора и во время
него. Портал закрыт до подтверждения последней реплики.

## Реестр и настройки

`RandomForest/datafiles/narrative/black_room.json` входит в Included Files.
`defaults` задаёт общие параметры, а каждая запись `scenes` может их переопределить:

```json
{
  "defaults": {
    "characters_per_second": 30,
    "fade_seconds": 0.33,
    "exploration_seconds": 3,
    "music": null
  },
  "scenes": [
    {
      "id": "ck_after_01",
      "enabled": true,
      "after_level": 1,
      "exploration_seconds": 5,
      "dialogue": "narrative/dialogues/ck_after_01.json"
    }
  ]
}
```

- `id` — стабильный ключ просмотра в `save.ini`; менять текст можно без смены ID.
- `enabled` — включён ли переход. Сейчас включена только ЧК после 01.
- `after_level` — номер уровня для человека, **с единицы**, а не внутренний индекс.
  На каждый уровень задаётся одна сцена.
- `dialogue` — путь относительно Included Files (`datafiles` в проекте).
- `exploration_seconds` — время свободного движения **после завершения входного
  затемнения** до первой реплики. Для первой сцены 5 секунд, для остальных 3.
  Пауза и обычная остановка игрового времени при прицеливании не расходуют задержку.
- `characters_per_second` — положительная скорость печати видимых символов.
- `fade_seconds` — положительная длительность входного/выходного затемнения.
- `music` — `null` для тишины или имя музыкального sound-ресурса GameMaker.
  Он должен быть добавлен в проект; выключатель музыки распространяется и на него.

После изменения JSON перезапустить игру: реестр читается при загрузке.
Новый файл диалога необходимо добавить в Included Files. Изменение существующих
файлов, порогов, задержек и включение заготовок не требуют изменения GML.

Выключенные заготовки после 09, 14, 20, 23, 26, 30, 32, 36, 40 и 41 отражают точки
зафиксированного таймлайна. Это проверочные монологи, без выдачи перков,
превращения и финальных действий. Заготовка после 41 не реализует концовку.

## Реплики и ветвления

Каждый `narrative/dialogues/ck_after_NN.json` содержит три части:

```json
{
  "opening": [
    {"speaker": "Голос", "text": "Тестовая сцена после {after_level}."}
  ],
  "variants": [
    {
      "when": {"all_in_range": [1, 8]},
      "lines": [{"text": "Память первых восьми уровней собрана."}]
    },
    {
      "when": {"collected_below_level_ratio": 0.5},
      "lines": [{"text": "Собрано меньше половины от номера этапа."}]
    },
    {
      "when": {},
      "lines": [{"text": "Собрано: [orange]{collected}[/orange]."}]
    }
  ],
  "closing": [
    {"text": "Конец теста.\nПортал открывается."}
  ]
}
```

Сначала звучит `opening`, затем **первый** подходящий вариант, затем `closing`.
Условия одной записи объединяются через «и». Последний вариант с `when: {}`
служит запасным. Для линейного разговора достаточно `opening` и `closing`,
а `variants` оставить пустым массивом.

| Условие | Значение |
| --- | --- |
| `min_collected` | Общее число собранных ОС не меньше значения. |
| `max_collected` | Общее число собранных ОС не больше значения. |
| `all_in_range: [1, 8]` | Собраны ОС всех уровней от 01 до 08 включительно. |
| `collected_below_level_ratio: 0.5` | Общее число ОС строго меньше `after_level × 0.5`. |

Для «меньше 20» используется `max_collected: 19`; для «ровно 36» — одновременно
`min_collected: 36` и `max_collected: 36`. Порядок вариантов задаёт приоритет
комментариев. В заготовке после 36 сильное предупреждение при количестве меньше
половины проверяется раньше ветки «меньше 20».

Прогресс ОС копируется при входе в ЧК. Ветвление и подстановки не меняются во время
разговора. Первая тестовая сцена линейная и не оценивает прогресс.

`speaker` необязателен, по умолчанию «Голос». В `text` поддерживаются:

- `\n` — явный перенос строки;
- `[orange]слова[/orange]` — насыщенное оранжевое выделение;
- `{collected}` — общее число ОС;
- `{after_level}` — отображаемый номер пройденного уровня.

Текст использует тот же пиксельный шрифт Glasstown, но со включённой кириллицей
и «Ё/ё». Используйте обычные три точки `...` вместо отдельного символа многоточия
и дефис вместо типографских тире. Цветовые теги не вложенные.

## Показ и управление

Плашка находится сверху экрана 480×270, с внешними отступами 12 пикселей и
внутренними 16. Шаг строк — 18 пикселей, максимум четыре строки на странице.
Полный текст измеряется до печати: слова не прыгают между строками по мере
появления букв. Длинные реплики автоматически продолжаются на следующей странице.

**Только Enter / Return** управляет разговором: сначала допечатать текущую страницу,
потом перейти дальше. Удержание не пролистывает страницы. Кнопки мыши, стрелки,
X и C разговор не переключают. Escape открывает обычную паузу, F меняет
полноэкранный режим. Диалог остаётся видимым при прицеливании мечом.

После последнего подтверждения плашка исчезает и портал вырастает до открытого
размера. Если игрок стоит в нём, надо отойти и вернуться: автоматического выхода
нет. После выхода появляется обычная статистика **исходного** уровня.

## Просмотр и прогресс

Результат уровня, достижения и следующий доступный уровень сохраняются при
входе в исходный портал. Время в ЧК не включается в рекорд.

В `save.ini`, секции `black_room_seen`, ID сцены отмечается только после выходного
затемнения. Разговор сам по себе не считается просмотренным. Если выйти в меню
или закрыть игру раньше, следующее прохождение исходного уровня снова покажет ЧК.
Автоматического возобновления из середины разговора нет.

«Начать заново» из паузы ЧК или её статистики открывает исходный игровой уровень.
«Дальше» открывает следующий уровень. Просмотренные сцены пропускаются при
повторном прохождении. Сброс кампании очищает просмотры; отдельный сброс рекордов
их сохраняет. Миграции старых сохранений нет: отсутствующие ключи означают,
что сцены ещё не просмотрены.
