# Фоны и ночные спрайты

## Правила подключения

Номера 01–20 используют день, 21–30 вечер, 31–40 ночь, 41 («00») утро.
Внутренние индексы API начинаются с нуля. Каталог содержит прежний набор уровней;
добавление будущих JSON обычным способом не требует новых условий в коде тем.

День импортирован из `.temp/background/Итог_темнее.png`, ночь из
`.temp/background/Ночь_итог.jpg`. Первоначальные фоны имели размер 625×352.
Удалены последний столбец и строка,
чтобы получить общий кадр 624×351 без перемещения оставшихся пикселей.
Фон результатов 480×270 получен из него через nearest-neighbor.
Вечер и утро теперь используют выбранные E4 «Синий час» и M4 «Золотой туман»:
заменены только фиксированные RGB леса, без размытия, сдвига пикселей и новой
геометрии. Оба разрешения импортированы независимо, прежних заглушек нет.

Для нового варианта спрайта или tileset добавьте к дневному имени `Evening`,
`Night` либо `Morning`, например `sSkeletonIdleEvening` или `tsPlatformsMorning`.
Для фонов суффикс темы предшествует `_x13`, например `sBackgroundNight_x13`.
Варианты должны сохранять размеры, origin, alpha, последовательность кадров и
настройки collision mask. Наборы тайлов также сохраняют индексы, разделители,
автотайлы и настройки анимации. После регистрации ресурса и перезапуска игры
он выбирается автоматически; отсутствующий вариант использует дневной ресурс.

Цветовые роли задаются в `scriptThemePresentation`: `accent`, `selected_border`,
`text`, `border`, `locked_text`, `inactive`, `locked_border`, `panel_muted`,
`movement_fx`. Ночь имеет собственную палитру, день сохраняет исходные значения.
Вечер/утро используют согласованные роли E4/M4, а движение — EV2/MO1.
При добавлении будущих ролей можно переопределить только нужные, остальные
продолжат наследовать день. Это отдельный механизм от
необязательных спрайтов: новый вариант изображения не требует менять всю палитру.

Меню используют единую презентацию сцены: цвета, панели, звёзды и будущие иконки
смешиваются с теми же четырьмя весами, что и фон. Совпадающие fallback-ресурсы
рисуются один раз. При смешивании разных изображений исходная alpha-маска
перекрывает фон один раз, затем добавляется взвешенный RGB; полупрозрачные
панели не темнеют в середине перехода. GPU blend state восстанавливается.
Дополнительные UI-поверхности и бессрочные GPU-кэши не создаются.

## Генерация и сохранение пикселей

### Выбранные вечер и утро, ночной летящий меч

В игру перенесены EV2 «Свет и тени» и MO1 «Рассеянный свет», без дополнительной
тонировки поверх одобренных PNG. Для каждой темы импортированы 53 ресурса
актёров (503 кадра): все состояния игрока, трёх врагов, их bloom, летящий меч,
огонь превращений, телепорт, воздушные эффекты, стрелки и таймер прицеливания.
Платформы/трава, оба набора шипов, панели и звёзды соответствуют выбранному
фону E4/M4; шесть tileset содержат готовые упакованные атласы с экструзией.
Белые маски прыжка/приземления получают EV2/MO1 `movement_fx` только в Draw.
Волна топота сохраняет прежний рефракционный шейдер без перекраски.

Имена конечных ресурсов — обычные `Evening`/`Morning`, не коды галереи.
Игровые Draw игрока, меча и огня превращения выбирают визуальный вариант,
не меняя базовый `sprite_index`, маску, углы и управление. В ЧК учитывается
текущий сюжетный скин; существующие тёмные ресурсы игрока не изменены.

Правонаправленный `sPlayerDarkTapSword` сохраняет все 18×5 пикселей, alpha,
origin (1,3), bbox и collisionKind дневного. Палитра непрозрачного клинка —
почти чёрный фиолетовый из `.temp/Player/Bonus/sword_dark.png`, рукоять сохранена.
Исходный фиолетовый ореол перенесён отдельно в `sSwordBloomNight`: RGB (90,0,255)
при прежнем alpha-профиле bloom. Ореол не расширяет боевую маску меча.
`tools/prepare_night_sword.py` готовит изолированный нативный RGB-bake;
шейдер используется только инструментом, не добавлен в рабочую игру.

`tools/import_selected_lighting.py` копирует одобренные кадры и editable layers
без перекодирования, клонирует текущие настройки масок/анимации и регистрирует
ресурсы. Он требует сохранённых исследовательских банков в `.temp` и перед
импортом проверяет, что исходные дневные кадры с момента согласования не менялись.
Для обычной сборки и аудита `.temp` не требуется: эталонные SHA256 по RGBA
зафиксированы в `tools/lighting_selection.json`. Проверка
`python3 tools/audit_selected_lighting.py` сверяет все 1022 кадра среды/актёров,
полные collision/alpha/animation contracts, packed tilesets и ночной меч.

Исторический импорт `tools/theme_assets.py import` предназначен для первоначального
комплекта и заглушек, не для восстановления нынешнего выбранного оформления.

### Первоначальный ночной комплект

Использован встроенный **imagegen**, по отдельному вызову для атласов слизня,
скелета, бунгало, платформ, обычных шипов и расширенных шипов. Во всех вызовах
первое изображение — текущие исходные кадры, второе — предоставленный ночной лес.
Дополнительно с навыком imagegen подготовлены дизайны девяти семейств: звёзды,
панели `sBorder3`/`sBorder4`, указатель, начало/конец телепорта, `sAirBack`,
`sAirBurst` и `sTapDestroy`. Их полные промпты сохранены в
[night-presentation-prompts.json](night-presentation-prompts.json).
Сохранены прозрачность и пиксельная структура исходных ресурсов, а не геометрия
перерисованных моделью изображений.

Общее требование промптов:

> Use case: lighting-weather. Image 1 is the EDIT TARGET: an original production
> pixel sprite atlas; image 2 is supporting nighttime forest lighting. Make
> EXACTLY THE SAME image pixel by pixel, ONLY changing the colors and nocturnal
> lighting. Preserve every silhouette, pose, tile layout, empty tile, separator,
> original pixel grid, individual frame count, and transparency. Do not redraw
> or invent details; do not move pixels. Keep labels unchanged. Transparent
> background. The final game will use this design's palette transferred to the
> exact original pixels. No neon outlines, no new particles, no blur around
> silhouettes.

Художественные дополнения к исходным промптам (до последующего выбора «Вереска»):

- Слизень: deep petroleum-blue/indigo body shadows, jewel-like teal and turquoise
  jelly highlights, small cool mint luminous highlights; existing red eye becomes
  pale icy cyan; matching subtle cyan bloom.
- Скелет: cold moonlit blue-white bone with periwinkle shadows, luminous icy-blue
  eye sockets and subtly radiant weapon edge; retain dark blue-grey metal and
  distinct bone/weapon materials.
- Бунгало: deep aubergine and indigo creature with jewel-like violet/lavender
  highlights and subtle glowing pale pink eye and weapon energy; legible dark
  body, no orange or yellow recolor.
- Платформы: deep midnight blue stone, blue-grey masonry edges, restrained
  turquoise luminous moss and softly moonlit grass; preserve readable platform
  top edges and tile seams; terrain less luminous than characters.
- Оба набора шипов: deep indigo bases and thorn shadows with softly luminous
  rose-violet thorn tips; readable danger silhouettes, restrained magenta
  accents, no cyan spikes; matching palettes for both atlases.

Полные промпты, исходные атласы, выбранные генерации и таблицы цветов находятся
в `.temp/night_art`. `tools/night_palettes.py` фиксирует согласованные палитры
по дизайнам, `tools/theme_assets.py` переносит RGB на исходные пиксели и
импортирует ресурсы. Оригинальные alpha-байты сохраняются, включая значения 1.
Трава получает отдельную палитру в тех же клетках атласа; новые пиксели не
добавляются. Bloom сохраняет исходный alpha-профиль и меняет цвет.
Каждый новый tileset содержит `output_tileset.png`: игровой упакованный атлас
с исходными индексами, прозрачностью и экструзией краёв. Одного spriteId
недостаточно для отображения тайлов при сборке вне редактора GameMaker.

Импортированы 42 новых арт-ресурса: 6 фонов, 18 анимаций врагов, 3 bloom,
3 спрайта окружения, 3 tileset и 9 спрайтов интерфейса/эффектов.
Вместе ночной комплект содержит 172 кадра.
Все конечные игровые PNG расположены в `RandomForest/sprites`, наборы тайлов —
в `RandomForest/tilesets`. Они зарегистрированы в `.yyp` и `.resource_order`.
Переимпорт использует стабильные идентификаторы и сохраняет порядок проекта.

## Согласованная палитра «Дымчатый вереск»

После сравнения четырёх вариантов выбрана схема C: лилово-серые платформы,
дымчатый мох и спокойные лавандовые роли интерфейса. Перенесены именно цвета
реальных игровых превью, включая звёзды и обе панели; оранжевая память,
красное здоровье, враги, игрок и остальные согласованные эффекты не изменены.
Общие роли применяются также к настройкам, справке, паузе, результатам и надписям.

Оба набора ночных шипов используют одну пыльно-лиловую палитру; самый светлый
оттенок — `#9E6FAA` вместо `#D46EDE`. Он заметнее верхней грани камня `#756C84`,
но меньше конкурирует с персонажами. Прозрачность не понижалась: изменён только
RGB, исходные alpha-байты и collision masks сохранены.

Цвета запечены в шесть существующих ночных спрайтов, их editable layers и три
упакованных tileset. Дополнительного игрового шейдера или цветовой обработки
каждого кадра нет. Вспомогательный renderer сохранён в исследовательском архиве
`tools_archive/prepare_night_palette_bake.py`: он готовит резервные копии,
а `--verify` проверяет точные RGBA
и ограничение записи пятнадцатью PNG. Все `.yy`, ID ресурсов и дневные изображения
остаются прежними. `tools/night_palettes.py` содержит выбранную палитру для
повторного импорта; таблица материалов сохраняет точное совпадение с превью,
в том числе исходные округления промежуточных цветов.

Галерея и исследовательские инструменты перенесены в
`.temp/night_palette_study/gallery` и `.temp/night_palette_study/tools_archive`.
В `docs` временной галереи больше нет. Другие материалы `.temp` при переносе
не удалялись и не перезаписывались. Новые runtime-проверки сохраняются отдельно
в `.temp/night_palette_study/heather-smoke` и `heather-smoke-basic`.

После внедрения прошли сборка рабочего проекта, все пять JS-наборов, аудит
масок/тайлов и проверка точной палитры. Оба реальных запуска завершились
`THEME_SMOKE_PASS` и `THEME_PRESENTATION_SMOKE_PASS`: проверены четыре темы,
ночные меню/пауза/результаты, переходы и реальные игровые эффекты. Сохранения
в тестовых копиях отключены.

## Проверка требований

Аудит всей визуальной цепочки, а не только фонов:

| Область | Ночное оформление | Сохранённые ограничения |
| --- | --- | --- |
| Главное меню, выбор уровней | Лилово-серые текст, рамки, звёзды, прогресс; синхронный crossfade | Движение камеры, размытие, управление и hit-test |
| Настройки, справка, пауза, результаты | Палитра родительской сцены; ночные панели и награды | Геометрия, анимации наград; результаты после ЧК |
| Враги и bloom | Нефритовый слизень, лунный скелет, фиолетовый бунгало | Все состояния, кадры, маски, урон, AI |
| Платформы, трава, оба набора шипов | Лиловый сланец, дымчатый мох, приглушённые пыльно-лиловые шипы | Индексы тайлов, alpha, коллизии, читаемость опасностей |
| Телепорт, вспышки, исчезновение меча | Холодная лавандовая магия вместо прежней зелёной | Исходные пиксели, origin, тайминги, маски |
| Прыжок/приземление, указатель | Лавандовый tint и холодное дерево | Форма, прозрачность; необязательные будущие варианты |
| Надписи на стенах | Холодные обычные надписи | Детерминированность и оранжевые сюжетные выделения |
| HUD, клавиши, нейтральные иконки/bloom | Предусмотрены необязательные sibling-ресурсы | Красное здоровье, белая информация, уже готовый игрок |

Ягоды, портал, обычные и оранжевые светлячки — намеренные исключения, не
«забытые» зелёные ресурсы. Их игровые и сюжетные цвета сохранены. День не
перекрашивается; вечер/утро используют выбранные варианты освещения.

- Подключены четыре темы, обе страницы дневных уровней, вечер, ночь и будущий «00».
- Подключены выбранные вечерние/утренние фоны, окружение и все анимации актёров.
  Дневной fallback сохранён для ресурсов, у которых нет тематического варианта.
- Оба меню сохраняют движение и размытие; смена темы плавная, повторное
  переключение начинает переход от видимой смеси без провала яркости.
- Экран результатов выбирает тему завершённого уровня, в том числе после ЧК.
  ЧК остаётся чёрной, пауза использует существующий снимок сцены.
- Ночные враги сохраняют базовые sprite_index, кадры, коллизии, урон и AI.
  Невидимые мечи-маски, solid/jump-through и trap-маски не изменены.
- Ягоды, портал, светлячки и готовые ресурсы игрока не изменены.
- Новые уровни, сюжетные сцены, способности, музыка и финал не добавлялись:
  это согласованная граница данной задачи относительно общего `.temp/plan.md`.

Автоматическая проверка: `python3 tools/audit_theme_assets.py` сравнивает полный
набор настроек collision masks, alpha каждого кадра, размеры, origin,
анимационные настройки, порядок кадров, editable layers и параметры tileset.
`node tools/tests/level-themes.test.cjs` выполняет исходный GML для границ тем,
fallback, будущих ресурсов, отрисовки без изменения масок, прерванных переходов,
передачи состояния меню, отражения движения, потери поверхностей и освобождения.
Финальная сборка основного проекта выполнена установленным GameMaker Runtime
2026.0.0.23. Все пять наборов JS-проверок `node --test tools/tests/*.test.cjs`
прошли, включая существующие проверки топота и надписей на стенах.
`tools/tests/theme-presentation.test.cjs` выполняет производственный GML для
цветовых ролей, контекста оверлеев, необязательных будущих ресурсов и смеси
RGB/alpha, включая восстановление blend state и точную дневную отрисовку.
`python3 tools/audit_theme_presentation.py` проверяет активные Draw-пути,
отсутствие прежних зелёных литералов в UI/движении, регистрацию Draw-событий
и неизменность исходных спрайтов (кроме выбранных вечерних/утренних фонов и
замены прежней дневной копии ночного меча).
Также прошли 8 Python-проверок формата уровней и регистрации каталога.
Полный старый набор генератора не объявляется пройденным: длительный seed-matrix
прогон остановлен; отдельно обнаружен существующий импорт отсутствующего
`generated_levels.review_batch` в `test_review_batch.py`. Генератор и эти тесты
в рамках задачи не изменялись.

`tools/prepare_theme_smoke.py` создаёт отдельную копию проекта с отключённой

Для утра используется существующая карта под индексом 40 только в тестовой

главное меню, выбор уровней, игру с мечом вправо/по диагонали и паузу для
