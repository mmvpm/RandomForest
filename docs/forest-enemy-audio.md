# Выбранные звуки лесных врагов

В игру установлены десять записей из [финального выбора](../randomforest-enemy-sound-selection-final.json).

| Персонаж | Событие | Выбор | Ресурс |
| --- | --- | --- | --- |
| Смоляной прыгун | Приземление | ПР10Р | `soundResinSlimeLand` |
| Смоляной прыгун | Выброс шипов | ПШ01Р | `soundResinSlimeAttack` |
| Коробейник спор | Взрыв бомбы | ВЗ04Р | `soundBarkBomberBurst` |
| Вересковая мышь | Налёт | МН15 | `soundForestBatAttack` |
| Вересковая мышь | Отлипание от потолка | МП01Р2 | `soundForestBatWake` |
| Берестяной страж | Выстрел | СС07Р2 | `soundBarkGuardShot` |
| Берестяной страж | Наземная атака | СЗ03Р3 | `soundBarkGuardImpact` |
| Полый жнец | Горизонтальный взмах | ЖВ08 | `soundRootReaperSweep` |
| Полый жнец | Вертикальный взмах | ЖУ24Р | `soundRootReaperSlam` |
| Корневая пасть | Выпад и укус | ПУ01 | `soundRootMawBite` |

ЖУ24Р содержит только выбранный бамбуковый взмах, без удара ЖУ02. Для wake взята именно выбранная МП01Р2. Мышь сидит под потолком и воспроизводит тихий wake один раз при отлипании; полёт и последующие налёты не вызывают wake повторно. Старые размещения без потолка начинают в полёте.

Атаки звучат один раз при переходе к активной фазе. Бомба звучит после отсчёта запала, а не при броске. У прыгуна единая физика прыжка: звук запускается при фактическом получении опоры, в том числе после воздушной атаки и hurt, без двойного срабатывания. Другим новым врагам звуки шагов не добавлены; звуки Сучника не изменены. Эффекты за пределами камеры не запускаются. Все новые ресурсы подчиняются настройке «Звуки».

Файлы сохранены целиком в PCM24, без новых срезов, растяжений, изменения высоты тона или индивидуальной нормализации. Общий коэффициент `1.9858205868` воспроизводит прослушивание в галерее: усиление превью +18 dB × громкость страницы 25%. Число сэмплов, стереоканалы, частота и относительные уровни сохраняются. GameMaker использует штатную конвертацию в несжатый PCM16 при сборке.

В изолированной игре проверены реальные вызовы воспроизведения всех десяти ресурсов, совпадение с активной фазой атаки / детонацией, отсутствие повторов и переключатель эффектов. [Лог](../.temp/enemy_audio_glow/runtime-console.log). После конвертации [проверены все WAV](../.temp/enemy_audio_glow/compiled-audio-audit.json): длины, каналы и частоты совпадают, расхождение с установленными файлами не превышает одного шага PCM16. Именно эти WAV целиком найдены внутри собранного `game.zip`.
